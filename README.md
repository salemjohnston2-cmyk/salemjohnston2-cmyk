What I'm Building

"Placebo" (https://github.com/salemjohnston2-cmyk/placebo)

An experimental programming language designed around expressing intent rather than implementation mechanics.

Placebo has its own lexer, parser, interpreter, runtime, functions, lambdas, collections, control flow, error handling, and browser playground.

v0.1.0 — experimental

---

NetSleuth

A deterministic web security reconnaissance tool that turns technical reconnaissance into a readable security report.

Built around DNS, TLS, HTTP security, technology detection, domain intelligence, subdomain discovery, CORS, sensitive-file exposure, WAF/CDN detection, and other reconnaissance modules.

---

Filter

An attempt to build technical infrastructure around AI safety and alignment.

The broader goal is to turn abstract alignment and governance concepts into measurable technical quantities rather than leaving them as purely theoretical language.

---

Intelligent P2P Routing

My final-year computer science project exploring deep-learning-based routing for peer-to-peer data dissemination.

Built as a simulation investigating whether learned routing decisions can improve network performance over traditional routing approaches.
